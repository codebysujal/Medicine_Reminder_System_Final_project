  # 💊 Medicine Reminder System

### A Console-Based Application Using C Programming

## 📌 Project Overview

The Medicine Reminder System is a console-based application developed using the C programming language.

This project was created as part of my first-year B.Tech group project. I worked on the coding, implementation and debugging of the application.

The main objective is to help users organize their medicine details and schedules through a simple menu-driven interface.

## 🚀 Features

- **Add Medicine:** Add medicine name, dosage, time, frequency and duration.
- **View Medicines:** Display all stored medicines.
- **Search Medicine:** Search for a medicine by its name.
- **Update Medicine:** Modify existing medicine details.
- **Delete Medicine:** Remove medicine records.
- **Daily Schedule:** Display saved medicine schedules.
- **File Handling:** Save and retrieve medicine records even after closing the program.

## 🛠️ Technologies Used

- **Language:** C Programming
- **IDE:** Code::Blocks
- **Compiler:** GCC
- **Concepts:** Structures, Arrays, Functions, Pointers, Strings, Loops, Switch-Case and File Handling

## 💻 How to Run

1. Download the repository.
2. Open `main.c` in Code::Blocks.
3. Build and run the program.
4. Choose an option from the menu.
5. Enter medicine details and manage your records.

## 📋 Main Menu

```
===== MEDICINE REMINDER SYSTEM =====

1. Add Medicine

5. Delete Medicine
6. Daily Schedule
7. Exit

Enter your choice:
```

## 📂 Data Storage

The program uses file handling to store medicine records in a binary file named `medicines.dat`.

Saved records are automatically loaded when the program starts again.
